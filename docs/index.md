!!! note "Qué es Java"
    Java es un lenguaje **tipado estático y orientado a objetos**. El código fuente (`.java`) se compila a *bytecode* (`.class`) que ejecuta la **JVM**, por lo que el mismo programa corre en cualquier sistema con una JVM.
