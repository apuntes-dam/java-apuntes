# U1: Primer programa en Java

## 1. Contexto

Esta unidad introduce el análisis de problemas, la escritura de programas sencillos y las herramientas para compilarlos, ejecutarlos y comprobarlos.

## 2. Objetivo de aprendizaje

Reconocer la estructura de un programa Java e identificar y relacionar los elementos propios del lenguaje.

## 4. Contenidos

1. [Un programa](01-programa.md): algoritmo, pseudocódigo y su traducción a Java.
2. [Práctica con el lenguaje](02-lenguaje.md): clase, `main`, variables, operadores, entrada y comentarios.
3. [Tipos de datos](03-tipos.md): primitivos, referencias y conversiones.
4. [Pruebas](04-pruebas.md): JUnit 5.
5. [Compilar y ejecutar](05-jdk.md): JDK, JVM y bytecode.
6. [Bucles](06-bucles.md): `for`, `forEach`, `while`.
