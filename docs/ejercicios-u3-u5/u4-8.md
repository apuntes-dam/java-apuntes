# U4.8 · Cambio de rol: explícamelo tú (grupos)

Cada grupo investiga un tema, prepara una presentación con demostración en vivo (10 min + 5 de preguntas) y se la explica al resto.

## Ejercicio 4.17

**Tema 1: expresiones regulares y funciones de extensión.**

1. ¿Qué es una expresión regular y para qué se usa? Explícala con un ejemplo práctico.
2. Localiza en tu práctica del ahorcado dónde la usas y analiza el código.
3. ¿Qué es una función de extensión (o su equivalente en tu lenguaje)?
4. Desarrolla `filtrar` para una lista de cadenas: recibe un patrón y devuelve los elementos que lo cumplen, emulando el comportamiento de `filter`.

!!! note "En Java"
    Java **no tiene funciones de extensión**: usa un método estático de utilidad (`Utilidades.filtrar(lista, patron)`) o un *default method* en una interfaz y explica la diferencia.

## Ejercicio 4.18

**Tema 2: genéricos.**

1. ¿Qué son los genéricos y para qué se usan? Explícalos con un ejemplo práctico.
2. Localiza en tu práctica del ahorcado dónde los usas y analiza el código.
3. Desarrolla una función `filtrar` **genérica** para cualquier lista de elementos de tipo `T`, que reciba una función `(T) -> Boolean` y devuelva los elementos que la cumplen.

!!! note "En Java"
    Java: método genérico `static <T> List<T> filtrar(List<T> lista, Predicate<T> cond)`.
